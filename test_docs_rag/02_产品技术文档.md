# 星桥智能客服系统 — 产品技术文档 v3.2

## 1. 产品概述

星桥智能客服系统（BridgeCS）是星桥科技的旗舰产品，于2019年首次发布，
目前已迭代至 3.2 版本。系统基于公司自研的 BridgeNLP 框架构建，
支持文本、语音、图片多模态输入，可与企业现有 CRM、ERP 系统深度集成。

**核心能力：**
- 意图识别准确率：97.3%（行业基准：91.2%）
- 平均响应时延：143ms
- 支持并发会话数：单节点 10,000+
- 多语言支持：中文、英文、日文、泰文

---

## 2. 系统架构

BridgeCS 采用微服务架构，核心组件如下：

### 2.1 对话引擎（DialogEngine）

负责管理多轮对话状态，基于有限状态机（FSM）与神经网络联合驱动。
当规则匹配置信度低于阈值（默认 0.75）时，自动切换至神经网络模式。

关键参数：
- `max_turns`：单次会话最大轮数，默认 50
- `timeout`：会话超时时间，默认 300 秒
- `fallback_threshold`：转人工阈值，默认 0.4

### 2.2 知识库模块（KnowledgeBase）

支持从以下数据源导入知识：
- Word/PDF 文档（自动解析）
- FAQ 表格（Excel/CSV）
- API 接口（实时拉取）
- 网页爬取（定时同步）

知识条目向量化使用公司自研的 Bridge-Embed-v2 模型（768 维），
检索策略采用混合检索（BM25 + 向量相似度，权重比 3:7）。

### 2.3 质检模块（QualityControl）

对所有机器回答进行实时评分，评分维度包括：
- 相关性（Relevance）：0-1 分
- 完整性（Completeness）：0-1 分
- 安全性（Safety）：0-1 分（低于 0.8 自动拦截）

## 4. 快速接入指南

### 4.1 安装 SDK

```bash
pip install bridgecs-sdk==3.2.0
```

### 4.2 初始化客户端

```python
from bridgecs import BridgeClient

client = BridgeClient(
    api_key="your_api_key",
    endpoint="https://api.starbridge-ai.com/v3",
    timeout=10,
)
```

### 4.3 发送消息

```python
response = client.chat(
    session_id="user_123",
    message="我的订单什么时候发货？",
    context={"user_id": "u001", "order_id": "ORD20240815"}
)

print(response.text)       # 回答文本
print(response.confidence) # 置信度
print(response.intent)     # 识别到的意图
```

## 5. 常见问题（FAQ）

**Q：系统是否支持私有化部署？**
A：支持。提供完整的 Docker 镜像和 Kubernetes Helm Chart，
   客户可在自有机房或私有云部署，数据不出本地网络。

**Q：知识库更新后需要重启服务吗？**
A：不需要。知识库支持热更新，新增/修改的知识条目在提交后 30 秒内生效。

**Q：如何处理超出知识库范围的问题？**
A：系统有三级兜底策略：
   1. 相似问题推荐
   2. 引导用户联系人工客服
   3. 记录未知问题日志，供运营人员后续补充

**Q：BridgeCS 与 ChatGPT 等大模型有何区别？**
A：BridgeCS 专为企业客服场景优化，强调确定性、可控性和合规性。
   而通用大模型适合开放式对话，但在企业级场景中存在幻觉风险和数据隐私问题。
   BridgeCS 3.2 版本已集成大模型能力，但对输出进行了严格的后处理过滤。
